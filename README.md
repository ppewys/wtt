# Where to ting?

เว็บช่วยค้นหาวิธีแยกขยะและดูจุดทิ้งขยะตัวอย่างในมหาวิทยาลัยมหิดล ศาลายา สร้างเป็น static site จึงเผยแพร่ด้วย GitHub Pages ได้โดยไม่ต้องมีเซิร์ฟเวอร์

## เปิดใช้งานบน GitHub Pages

1. อัปโหลด repository นี้ขึ้น GitHub และตั้งชื่อ branch หลักเป็น `main`
2. ใน repository ไปที่ **Settings → Pages** แล้วตั้ง **Build and deployment → Source** เป็น **GitHub Actions**
3. รอ workflow `Deploy static site to GitHub Pages` ทำงานสำเร็จ จากนั้นเปิด URL ที่แสดงใน **Settings → Pages**
4. หากต้องการให้ทุกคนเข้าถึง ให้ตั้ง repository เป็น Public ตามการตั้งค่าและแผน GitHub ของคุณ

การ push ไปยัง `main` ครั้งถัดไปจะ deploy หน้าเว็บให้อัตโนมัติ หรือสั่ง deploy เองได้จาก **Actions → Deploy static site to GitHub Pages → Run workflow**

## ฟีเจอร์และข้อจำกัด

- ค้นหาชื่อขยะด้วยกฎพื้นฐานได้โดยไม่ต้องตั้งค่า API
- เพิ่ม Gemini API key ในหน้าเว็บเพื่อวิเคราะห์รูปภาพหรือใช้ AI จัดประเภทคำค้นหา คีย์เก็บใน session ของเบราว์เซอร์และส่งตรงไปยัง Google เท่านั้น อย่าใช้คีย์ที่มีสิทธิ์สำคัญหรือโควตาที่ไม่ต้องการเปิดเผยบนเว็บสาธารณะ
- จุดทิ้งขยะตั้งต้นเป็นข้อมูลตัวอย่าง ส่วนจุดที่ผู้ใช้เสนอจะเก็บใน local storage ของเบราว์เซอร์นั้น ไม่ได้ส่งหรือแชร์กับผู้ใช้คนอื่น
- ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์ ไอคอน แผนที่ และบริการ Gemini
